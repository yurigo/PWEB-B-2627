Tags semánticos

Tags básicos

Los tags semánticos son aquellos que tienen un significado específico y ayudan a estructurar el contenido de una página web. Algunos ejemplos de tags semánticos son:

  • <header>: Representa la cabecera de un documento o sección.
  • <nav>: Representa un conjunto de enlaces de navegación.
  • <main>: Representa el contenido principal de un documento.
  • <article>: Representa un contenido independiente y autocontenido.
  • <section>: Representa una sección genérica de un documento.
  • <aside>: Representa contenido relacionado con el contenido principal, pero que no es parte de él.
  • <footer>: Representa el pie de página de un documento o sección.

Div vs Button

Un boton ya soporta activación por teclado, enfoque, estado deshabilitado y semántica esperada. Un div estilizado para parecer un botón no proporciona ninguno de esos comportamientos automáticamente. Comience con el elemento nativo que coincida con la acción. Agregue ARIA solo cuando HTML no pueda expresar el significado requerido; ARIA no repara un modelo de interacción

details

El elemento <details> es un elemento HTML que se utiliza para crear un widget interactivo que permite a los usuarios mostrar u ocultar información adicional. El contenido dentro del elemento <details> se oculta de forma predeterminada y se puede mostrar haciendo clic en el resumen o encabezado del elemento.

Formulario

Un formulario HTML es un conjunto de elementos que permiten a los usuarios enviar información a un servidor web. Los formularios se utilizan para recopilar datos de los usuarios, como nombres, direcciones de correo electrónico, contraseñas, preferencias y otra información relevante.

Ver ejemplo de formulario

Si bien podemos crear formularios sin usar la etiqueta <form>, es recomendable usarla para una mejor estructura y accesibilidad.
